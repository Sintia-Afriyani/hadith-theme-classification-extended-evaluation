# Curated Dataset v1.1

This directory contains the curated benchmark of 1,323 English hadith translations used in the revised experiments.

The dataset excludes six narrations based on source-provided grading metadata. The operational labels are derived from selected source-book titles and do not represent independently verified semantic ground truth.

Source dataset: freococo/sunnah_dataset (CC BY-NC-SA 4.0).

Dataset redistribution and attribution requirements must be verified before public release.
